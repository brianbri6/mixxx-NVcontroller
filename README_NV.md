## Build scope

This repository retains its existing upstream Mixxx source. The native LCD
exporter and Pi updater in `bitedj-nv/` target TeamDeckshark/bitedj revision
`78074e05c8bf99ede6fedd755aa68bd222ba343c` (Mixxx 2.5.6 base).
They are not wired into this fork's newer Mixxx CMake/core services.
Building the root Mixxx project includes the controller mapping; it does not
by itself enable the NV LCD service. Follow `bitedj-nv/README.md` for the tested
Pi integration and pinned build inputs. Do not apply its native patch blindly
to the root Mixxx tree.
